# Web Research Assistant

A Python-based research assistant project focused on searching, organising, and retrieving relevant research notes. The project is being developed incrementally, with the long-term goal of evolving into an AI-powered research assistant.

## Current Capabilities

- Search research notes using query keywords.
- Rank search results based on the number of query words matched.
- Handle empty search queries safely.
- Identify relevant notes and return the most useful matches first.

## Technical Learnings

- **Relevance ranking:** Research notes are ranked by the number of query words they match, so more relevant notes appear first.
- **Test-driven development:** Writing a failing test first helps define expected behaviour before implementing a change.
- **Empty query handling:** Returning an empty list for an empty search query avoids returning irrelevant results.
- **Search relevance:** Ranking results by keyword matches helps users find the most relevant research notes first.
